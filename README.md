# JMComic Web（纯静态版）

由 [JMComic-Next](../JMComic-Next) 移植而来的纯前端版本：没有 Python 后端，所有请求由浏览器直接发往 JM 公开接口和图源。

## 保留的功能

- 发现、最新更新、分类浏览、搜索与筛选、作品详情、评论、内容预览
- 阅读器：浏览器直连图源、附近页面按需加载、失败换线、图源与并发设置
- 详情页“翻译标题”（谷歌翻译，免 Key）
- 浏览器内保存：最近阅读、随机历史、稍后再看、最近 50 条搜索记录、上次阅读章节
- 浏览器接口缓存：作品资料 7 天、章节 3 天、分类和首页推荐 1 天、API 线路 6 小时，最多 300 项；可在“设置 → 清除接口缓存”手动清理

## 已移除

账号登录、收藏、喜欢、追更、消息、签到；本地评分；标签/作者偏好；AI 标题翻译与 AI 整理；服务器端缓存与历史迁移；网页章节名补全（缺少章节名时显示“第N话”）。

## 运行

页面使用 ES 模块，不能直接双击打开 `index.html`（`file://` 下模块无法加载），需要任意静态服务器，例如：

```bash
python3 -m http.server 8080 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8080/`，按 `Ctrl+C` 停止。也可以把整个文件夹部署到任意静态托管服务。

所有数据只保存在当前浏览器的 localStorage 中，不同浏览器、域名或端口互不共享。
