# JMComic Web

🌐 **在线访问：<https://jm.ignat.ai>**

一个纯绿色、开源、无广告的 JM 漫画网页阅读站。

## 特点

- **纯绿色、无广告**：没有任何广告、追踪或多余的内容。
- **开源**：代码完全公开，使用 [Apache License 2.0](LICENSE) 协议。
- **纯静态实现**：只有 HTML、CSS 和 JavaScript，没有后端。
- **托管在 Cloudflare Workers**：以静态资源方式部署。
- **浏览器直连 JM 官方服务器**：没有任何中间服务器，不经过任何代理或转发。

## 网络连接说明

本站没有任何中间服务器，访问是否顺畅完全取决于你的网络：

| 现象 | 取决于 |
| --- | --- |
| 能否正常打开本网站 | 你的设备与 Cloudflare 之间的连接性能 |
| 能否正常加载漫画资源 | 你的设备与 JM 官方服务器之间的连接性能 |

如果网站打不开或漫画加载缓慢，请优先检查并调整你的网络环境。

## 功能限制
